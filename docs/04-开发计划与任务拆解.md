## 5. 风险与缓冲

| 风险 | 影响 | 缓冲措施 |
|------|------|---------|
| 结构体循环引用检测复杂度超预期 | T16 延期 2-4h | T16 工时已含 2h 缓冲；可先实现基础版，复杂循环引用作为已知限制 |
| validx 集成 API 不匹配 | T20 延期 | 提前阅读 validx 源码确认 API；预留 T24 整合时间 |
| 时间格式自动识别覆盖不全 | T14 返工 | 参考 cast 的格式列表；T28 fuzz 测试兜底 |
| 性能不达标 | T27 发现问题 | V1 性能目标已放宽至与竞品持平；不达标则记录为 V2 优化项，不阻塞发布 |
| 跨平台测试失败 | T33 阻塞 | CI 从 T06 起持续运行，尽早发现平台差异 |

**总缓冲**：104h 预估中已含约 15% 缓冲（约 14h），分散在各任务中。
