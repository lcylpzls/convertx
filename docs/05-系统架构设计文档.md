## 1. 整体架构说明

### 1.1 架构定位

convertx 是**无状态基础库**，不持有长连接、不启动后台 goroutine、不依赖外部服务。所有 API 为纯函数式调用：输入 → 转换 → 输出，调用完毕后无残留状态（全局转换器注册表除外，init 阶段写入后运行时只读）。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **分层隔离** | 根部 API 层仅做转发，核心逻辑集中在 `internal/core`，外部无法直接引用内部实现 |
| **单一职责** | 每个转换类别独立文件（scalar/struct/map/collection/time），互不依赖核心调度器 |
| **错误优先** | 所有路径返回 `(T, error)`，错误通过 errx 统一封装，禁止 panic、禁止吞错 |
| **可扩展** | 转换器注册表机制允许用户覆盖/补充内置转换，无需修改库源码 |
| **零全局可变状态** | 除 init 阶段写入的只读注册表外，无运行时可变全局状态 |

## 2. 分层架构

```
┌─────────────────────────────────────────────────────────┐
│                    接入层 (API Layer)                     │
│  api.go — 类型别名 + 函数转发，唯一对外暴露面              │
│  doc.go — 包文档注释                                      │
├─────────────────────────────────────────────────────────┤
│                  调度层 (Dispatcher Layer)                │
│  convert.go — 核心调度：查找转换器 → 执行转换 → 错误封装   │
│  options.go — 选项解析与传递                               │
│  registry.go — 自定义转换器查找                            │
├─────────────────────────────────────────────────────────┤
│                  实现层 (Converter Layer)                 │
│  scalar.go    基础类型转换                                 │
│  struct.go    结构体转换                                   │
│  map.go       struct ↔ map 互转                           │
│  collection.go 集合类型转换                                │
│  time.go      时间类型转换                                 │
│  pointer.go   指针解引用与重建                             │
│  validate.go  校验集成（validx 委托）                      │
├─────────────────────────────────────────────────────────┤
│                基础设施层 (Infrastructure Layer)           │
│  errors.go     错误码定义                                  │
│  error_util.go errx 封装辅助函数                           │
│  default.go    默认值机制                                  │
│  struct_meta.go 结构体字段元信息反射解析                    │
│  version.go    版本常量                                    │
└─────────────────────────────────────────────────────────┘
         │
         ▼ 依赖
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│   errx (运行时)  │  │  validx (运行时) │  │  testx (测试)   │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

### 2.1 各层职责

| 层 | 职责 | 依赖方向 |
|----|------|---------|
| 接入层 | 暴露稳定公开 API，类型别名，函数转发到 core | 仅依赖调度层 |
| 调度层 | 转换流程编排：参数校验 → 查找转换器 → 执行 → 校验 → 错误封装 | 依赖实现层 + 基础设施层 |
| 实现层 | 各类别的具体转换逻辑，通过调度层的接口被调用 | 依赖基础设施层，互不直接依赖 |
| 基础设施层 | 错误码、错误封装、默认值、反射元信息、版本 | 仅依赖标准库 + errx |

### 2.2 层间调用规则

- 接入层 **不得** 包含任何业务逻辑，仅做 `type X = core.X` 和 `func X(...) { return core.X(...) }`
- 调度层 **不得** 直接依赖具体转换实现的内部函数，通过统一的 `convert(src, dstType, opts)` 入口调度
- 实现层各文件 **不得** 互相调用，如需跨类别转换（如结构体字段是 slice），递归调用调度层 `convert()`
- 基础设施层 **不得** 反向依赖调度层或实现层

| 文件 | 层 | 核心职责 | 关键导出（内部） |
|------|----|---------|----------------|

| `doc.go` | 接入层 | 包文档 | — |
| `convert.go` | 调度层 | 核心调度入口 | `Convert(src, dstType, opts) (any, error)` |
| `options.go` | 调度层 | 选项定义与解析 | `Option`、`WithXxx()` 系列 |
| `registry.go` | 调度层 | 自定义转换器注册与查找 | `RegisterConverter`、`LookupConverter` |
| `scalar.go` | 实现层 | 基础类型互转 | `convertScalar` |
| `struct.go` | 实现层 | struct ↔ struct 转换 | `convertStruct` |
| `map.go` | 实现层 | struct ↔ map 互转 | `convertStructToMap`、`convertMapToStruct` |
| `collection.go` | 实现层 | slice/map 集合转换 | `convertSlice`、`convertMap` |
| `time.go` | 实现层 | 时间类型转换 | `convertTime` |
| `pointer.go` | 实现层 | 指针解引用/取地址 | `dereference`、`reference` |
| `validate.go` | 实现层 | validx 校验集成 | `validateValue` |

| `error_util.go` | 基础设施 | errx 封装辅助 | `wrapError`、`withFieldPath` |
| `default.go` | 基础设施 | 默认值机制 | `applyDefault` |
| `struct_meta.go` | 基础设施 | 结构体字段元信息反射 | `parseStructMeta`、`FieldMeta` |

### 3.2 模块依赖关系

```
api.go ──→ convert.go ──→ registry.go
              │
              ├──→ scalar.go
              ├──→ struct.go ──→ struct_meta.go
              ├──→ map.go ─────→ struct_meta.go
              ├──→ collection.go
              ├──→ time.go
              ├──→ pointer.go
              └──→ validate.go ──→ validx
              │
              └──→ error_util.go ──→ errx
                   default.go
```

**无循环依赖**：实现层各文件均不互相 import，跨类别转换通过 `convert.go` 递归入口完成。

## 4. 核心流程设计

### 4.1 标准转换流程（convert.go）

```
输入: src any, dstType reflect.Type, opts []Option
  │
  ▼
1. 解析选项（默认值、严格模式、校验规则等）
  │
  ▼
2. nil 检查：src == nil？
   ├─ 是 → 有默认值返默认值；否则返 ErrConversionFailed
   └─ 否 ↓
  │
  ▼
3. 指针解包：src 是指针？→ 递归解引用至非指针（记录指针层级）
  │
  ▼
4. 类型匹配：src.Type() == dstType？
   ├─ 是 → 直接返回（值复制）
   └─ 否 ↓
  │
  ▼
5. 查找自定义转换器：registry.Lookup(srcType, dstType)
   ├─ 命中 → 执行自定义转换器
   └─ 未命中 ↓
  │
  ▼
6. 按 dstType.Kind() 分发到内置转换器：
   ├─ Basic(Int/Uint/Float/Bool/String) → scalar.go
   ├─ Struct → struct.go
   ├─ Map → map.go / collection.go
   ├─ Slice/Array → collection.go
   ├─ Interface → 递归解包
   └─ 其他 → ErrConversionFailed
  │
  ▼
7. 转换结果处理：
   ├─ 失败 → 封装 errx（含 source_type/target_type/field_path）
   └─ 成功 ↓
  │
  ▼
8. 指针重建：目标是指针类型？→ 按记录的层级取地址
  │
  ▼
9. 校验：有校验选项？→ 调用 validx，失败返 ErrValidationFailed
  │
  ▼
10. 返回 (结果, nil)
```

### 4.2 结构体转换流程（struct.go）

```
输入: srcVal reflect.Value, dstVal reflect.Value, opts
  │
  ▼
1. 解析目标结构体元信息（struct_meta.go，V2 缓存）
  │
  ▼
2. 循环引用检测：srcVal 是指针且已访问？→ ErrCircularReference
  │
  ▼
3. 遍历源结构体每个字段：
   ├─ tag == "-" → 跳过
   ├─ 查找目标字段（tag名 → 字段名）
   │   ├─ 未找到 → 严格模式？记录 ErrUnmatchedField : 跳过
   │   └─ 找到 ↓
   ├─ 字段类型相同 → 直接 Set
   └─ 字段类型不同 → 递归调用 convert()（携带 field_path 前缀）
  │
  ▼
4. 返回 error 或 nil
```

### 4.3 自定义转换器注册流程（registry.go）

```
RegisterConverter[Src, Dst](fn func(Src)(Dst,error)):
  │
  ▼
1. 计算 key = (reflect.TypeOf(Src), reflect.TypeOf(Dst))
  │
  ▼
2. 加写锁，检查 key 是否已存在
   ├─ 存在 → 返 ErrDuplicateConverter
   └─ 不存在 → 存入 map，返 nil
  │
  ▼
运行时 Lookup(key):
  加读锁，从 map 查找，返回 (fn, found)
```

## 6. 容错策略

### 6.1 错误处理

| 容错点 | 策略 |
|--------|------|
| 类型断言失败 | 使用 `v, ok := x.(T)` 安全断言，不使用 `x.(T)` 裸断言 |
| nil 指针解引用 | 转换前统一 nil 检查，指针解引用时逐层检查 |
| 数值溢出 | 转换前比较源值与目标类型边界，溢出返 ErrOverflow |
| 数组/slice 越界 | 不使用静态索引访问，全部通过 range 或长度检查 |
| 自定义转换器 panic | `defer recover()` 捕获，转为 ErrConversionFailed（防御性） |
| 结构体循环引用 | 维护已访问指针集合（`map[uintptr]bool`），检测到循环返 ErrCircularReference |
| map 并发读写 | 注册表使用 `sync.RWMutex` 保护；转换过程不修改输入 map |

### 6.2 错误封装规范

所有错误通过 `error_util.go` 的统一入口封装：

```
wrapError(err, sourceType, targetType, fieldPath, valuePreview)
  → errx.New(code).WithKind(kind).WithKV(...)
```

- `source_type`：源类型字符串（如 `string`、`*int`）
- `target_type`：目标类型字符串
- `field_path`：嵌套路径（如 `User.Address.City`，顶层为空）
- `value_preview`：源值截断至 100 字符的字符串表示

### 6.3 部分失败策略

| 场景 | 策略 |
|------|------|
| 集合转换单个元素失败 | **整体失败**，不返回部分结果，错误携带失败元素索引 |
| 结构体转换单个字段失败 | **整体失败**，错误携带 field_path，目标结构体可能已部分赋值（调用方应视为无效） |
| 校验失败 | 转换值已生成但不返回，仅返回错误 |

## 7. 降级与回退策略

### 7.1 转换器查找回退

```
查找转换器:
  1. 自定义注册表（最高优先级）
  2. 内置精确匹配（源类型→目标类型直接转换）
  3. 内置间接匹配（通过中间类型，如 string→float64→int）
  4. 全部失败 → ErrConversionFailed
```

### 7.2 时间格式回退

string → time 时按优先级列表依次尝试，首个成功即返回，全部失败返 `ErrUnknownFormat`。指定 `WithTimeLayout` 时仅尝试指定格式，不回退。

### 7.3 V2 高性能路径回退（预留）

V2 引入零反射快速路径时：
- 快速路径适用条件不满足（如含自定义转换器、复杂嵌套）→ 自动回退到反射路径
- 回退对调用方透明，API 行为不变
- 回退次数可通过 metrics 统计（V2 可选接入 metricsx）

## 8. 扩展性设计

> 基础库无"扩容"概念，本节描述功能扩展性。

### 8.1 自定义转换器扩展

用户通过 `RegisterConverter[Src, Dst](fn)` 注册业务类型转换，无需修改库源码。注册表全局生效，优先级高于内置。

### 8.2 选项模式扩展

新增转换行为通过 `Option` 函数注入，不破坏已有 API 签名：

```go
type Option func(*convertConfig)

func WithDefault(v any) Option       // 已有
func WithStrictMode() Option         // 已有
func WithValidation(rules string) Option  // 已有
func WithTimeLayout(layout string) Option // 已有
// 新增选项只需添加函数，不影响已有调用方
```

### 8.3 V2 性能扩展点

| 扩展点 | V1 状态 | V2 计划 |
|--------|---------|---------|
| 结构体元信息缓存 | 每次反射解析 | `sync.Map` 缓存，按类型缓存 FieldMeta |
| 基础类型快速路径 | 反射 + 类型断言 | 泛型特化，零反射 |
| 转换器链缓存 | 每次查找 | 按 (srcType,dstType) 缓存转换函数链 |

## 9. 安全约束

| 约束 | 说明 |
|------|------|
| 禁止 panic | 所有导出函数路径无 panic；内部 recover 仅用于防御自定义转换器 panic |
| 禁止吞 error | 不提供仅返值不返 error 的 API 变体 |
| nil 安全 | 任何输入（nil 指针、nil interface、nil slice/map）不导致 panic |
| 并发安全 | 导出 API 无共享可变状态；注册表读写锁保护；可安全并发调用 |
| 错误信息脱敏 | `value_preview` 截断至 100 字符，避免大值或敏感数据完整泄露 |
| 不执行外部代码 | 不解析或执行源值中的任何表达式、脚本、命令 |
| 不持有资源 | 不打开文件、不建立连接、不启动 goroutine，调用完毕无残留 |
| 自定义转换器安全边界 | 转换器由用户提供，其行为（包括 panic）由用户负责；库仅做防御性 recover |

## 10. 性能设计

### 10.1 V1 性能特征

- 基础类型转换：反射类型判断 + 类型断言直转，与 cast 同量级
- 结构体转换：每次反射解析字段元信息（V2 缓存优化），与 mapstructure 同量级
- 集合转换：逐元素转换，线性时间
- 内存分配：每次转换分配目标值，反射相关临时对象

### 10.2 减少分配的设计

- 错误对象复用：`errx.New` 内部池化（依赖 errx 实现）
- 结构体元信息：V1 每次解析，V2 引入缓存
- 切片转换：预分配目标 slice 容量（`make([]Dst, len(src))`）

### 10.3 Benchmark 基线

| 场景 | 对标竞品 | V1 目标 |
|------|---------|---------|
| string→int（100万次） | spf13/cast | 持平 ±10% |
| 10字段 struct→struct | mapstructure | 持平 ±15% |
| 1000元素 []string→[]int | 手写循环 | ≤ 3倍开销 |
