## 2. 核心需求（P0）

### C01 基础类型互转

| 维度 | 内容 |
|------|------|
| **场景** | 配置文件解析、API 请求参数处理、动态数据归一化时，将 `interface{}` / `string` 转为强类型数值 |
| **输入** | 源值（任意基础类型或其指针）、目标类型（通过泛型参数或函数名指定） |
| **输出** | 目标类型值 + `errx.Error`；转换失败时返回零值和错误 |
| **约束** | 覆盖类型：`string`、`int`/`int8`/`int16`/`int32`/`int64`、`uint`/`uint8`/`uint16`/`uint32`/`uint64`、`float32`/`float64`、`bool`、`byte`、`rune`；数值转换需检测溢出；`string→bool` 仅识别 `"true"/"false"/"1"/"0"/"t"/"f"`（大小写不敏感）；禁止 panic、禁止吞 error |
| **验收标准** | ① 所有基础类型两两互转均有对应函数；② 溢出返回 `errx` 错误并携带源值与目标类型；③ 非法字符串转数值返回明确错误；④ 100% 单测覆盖正常/边界/异常路径 |

### C02 结构体之间转换（struct ↔ struct）

| 维度 | 内容 |
|------|------|
| **场景** | 领域模型 DO 与 DTO/VO 之间的字段复制与类型转换，如 `UserDO → UserVO` |
| **输入** | 源结构体值（或指针）、目标结构体指针、可选配置项（tag 名、忽略零值等） |
| **输出** | 填充后的目标结构体 + `errx.Error` |
| **约束** | 同名字段自动映射；支持 `convertx:"target_name"` tag 自定义映射；支持 `convertx:"-"` 忽略字段；嵌套结构体递归转换；字段类型不同时调用基础类型转换器；未匹配字段不报错（可配置为严格模式报错）；源为 nil 指针返回零值结构体 |
| **验收标准** | ① 同名字段自动映射正确；② tag 映射优先级高于字段名；③ 嵌套结构体递归转换；④ 异类型字段自动调用基础转换；⑤ 循环引用检测并返回错误（不栈溢出）；⑥ 单测覆盖同/异名、嵌套、指针、未匹配、循环引用场景 |

### C03 结构体与 map 互转（struct ↔ map[string]any）

| 维度 | 内容 |
|------|------|
| **输入** | struct → map：源结构体值；map → struct：源 `map[string]any`、目标结构体指针 |
| **输出** | struct → map：`map[string]any`；map → struct：填充后的结构体 + `errx.Error` |
| **约束** | map key 默认使用字段名，可通过 tag 自定义；嵌套结构体转为嵌套 map；map 中多余 key 默认忽略（可配置严格模式）；map → struct 时值类型不匹配调用基础转换器；支持 `map[string]string` 等强类型 map 转 struct |
| **验收标准** | ① struct→map 字段完整且 key 正确；② map→struct 字段赋值正确；③ 嵌套结构递归处理；④ 多余 key 默认忽略不报错；⑤ 严格模式下多余 key 返回错误；⑥ 单测覆盖正向/反向/嵌套/强类型map场景 |

### C04 集合类型转换

| 维度 | 内容 |
|------|------|
| **场景** | `[]string` → `[]int`、`map[string]string` → `map[string]int`、slice 与 map 互转等批量类型转换 |
| **输入** | 源集合（slice / map）、目标元素类型 |
| **输出** | 目标类型集合 + `errx.Error`；任一元素转换失败则整体返回错误，不返回部分结果 |
| **约束** | slice→slice：元素类型不同时逐元素调用转换器；map→map：key 和 value 均可异类型转换；slice→map：需指定 key 提取函数（通过选项或回调）；map→slice：值提取为 slice；nil 集合返回 nil 集合（非空集合）；保留元素顺序（slice） |
| **验收标准** | ① 异元素 slice 转换正确；② 异 key/value map 转换正确；③ 单个元素失败时整体返回错误且无部分结果；④ nil 输入返回 nil；⑤ 单测覆盖各类组合及失败场景 |

### C05 时间类型转换

| 维度 | 内容 |
|------|------|
| **场景** | 字符串时间解析、时间戳与 `time.Time` 互转、时区转换、持续时间解析 |
| **输入** | 源值（`string` / `int64` / `time.Time` / `time.Duration`）、目标类型、可选时区/格式参数 |
| **输出** | 目标类型值 + `errx.Error` |
| **约束** | string→time：自动识别 RFC3339、RFC822、`2006-01-02 15:04:05` 等常见格式，可指定格式；time→string：默认 RFC3339，可指定格式；int64→time：自动识别秒/毫秒/微秒/纳秒精度（按数值范围推断）；time→int64：可指定精度；时区转换：支持 `time.Time.UTC()`、`Local()`、指定 `*time.Location`；string 带时区偏移时保留时区，不带时默认 Local（可配置默认 UTC）；`time.Duration` 支持 `string`（如 `"1h30m"`）互转 |
| **验收标准** | ① 各常见格式字符串解析正确；② 时间戳精度自动识别正确；③ UTC↔Local 转换结果正确；④ 非法格式/越界时间戳返回错误；⑤ 单测覆盖各格式、各精度、时区转换、异常输入 |

### C06 指针处理

| 维度 | 内容 |
|------|------|
| **场景** | API 可选参数（`*int`）、数据库可空字段、嵌套结构体指针的转换与重建 |
| **输入** | 任意层级指针源值（`*int`、`**struct`、`*string` 等）、目标类型 |
| **输出** | 目标类型值（指针或非指针）+ `errx.Error` |
| **约束** | 指针解引用：`*T` → `T` 自动解引用，nil 指针返回零值（可配置为返回错误）；指针重建：`T` → `*T` 自动取地址；多级指针：`**T` → `T` 递归解引用，`T` → `**T` 递归取地址；nil 安全：任何层级 nil 指针不 panic；结构体转换中指针字段按上述规则处理 |
| **验收标准** | ① 一级指针解引用/取地址正确；② 多级指针递归处理正确；③ nil 指针不 panic 且返回零值或错误（按配置）；④ 结构体指针字段转换正确；⑤ 单测覆盖各层级 nil/非 nil 场景 |

### C07 默认值机制

| 维度 | 内容 |
|------|------|
| **场景** | 配置项缺失、可选参数为空时，转换失败应返回业务默认值而非错误 |
| **输入** | 源值、目标类型、默认值（同目标类型） |
| **输出** | 转换成功返回转换值；转换失败或源为零值/nil 时返回默认值 |
| **约束** | 提供 `WithDefault(v)` 选项或 `ToXxxOrDefault(src, def)` 系列函数；默认值仅在转换失败或源为零值时生效；源为非零值但转换非法时，同样返回默认值（不返回错误）；默认值机制不改变 C01-C06 的错误返回语义，仅为额外便捷 API |
| **验收标准** | ① 转换成功时返回转换值而非默认值；② 转换失败时返回默认值；③ 源为零值/nil 时返回默认值；④ 默认值类型与目标类型一致；⑤ 单测覆盖成功/失败/零值/默认值匹配场景 |

### C08 自定义转换函数注册

| 维度 | 内容 |
|------|------|
| **场景** | 业务自定义类型（如枚举 `Status`、`decimal.Decimal`、`uuid.UUID`）需要专用转换逻辑 |
| **输入** | 源类型、目标类型、转换函数 `func(SrcType) (DstType, error)` |
| **输出** | 注册成功 / 重复注册返回错误 |
| **约束** | 全局注册表，init 阶段注册（运行时只读）；按 (源类型, 目标类型) 唯一键注册；自定义转换器优先级高于内置转换器；支持覆盖内置转换器；注册函数必须返回 `error`，禁止 panic；转换器内部错误通过 `errx` 封装后向上传递 |
| **验收标准** | ① 注册后转换调用自定义函数；② 自定义优先级高于内置；③ 重复注册返回错误；④ 转换器返回的错误被正确透传；⑤ 并发读取注册表安全；⑥ 单测覆盖注册/覆盖/重复/并发场景 |

### C09 转换后自动校验

| 维度 | 内容 |
|------|------|
| **场景** | API 入参转换后需立即校验范围（如 `string→int` 后校验 `min=0`），减少样板代码 |
| **输入** | 源值、目标类型、校验规则（`validx` 规则字符串或 `validx.Rule` 列表） |
| **输出** | 转换且校验通过的目标值 + `errx.Error`；转换失败返转换错误；校验失败返校验错误（通过 errx 封装） |
| **约束** | 基于 `validx` 引擎；校验规则格式与 validx 一致（如 `"min=0,max=100"`）；转换成功后才执行校验；校验失败时返回的错误携带字段名和规则信息；与 C01-C06 各转换函数组合使用（通过选项传入校验规则） |
| **验收标准** | ① 转换成功且校验通过返回值；② 转换失败返回转换错误（不执行校验）；③ 校验失败返回校验错误且不返回部分值；④ 错误信息携带规则上下文；⑤ 单测覆盖转换成功校验通过/失败、转换失败、规则格式错误场景 |

### C10 独立校验快捷 API

| 维度 | 内容 |
|------|------|
| **场景** | 已有强类型值，仅需校验不需转换（如结构体字段校验、函数入参校验） |
| **输入** | 待校验值、校验规则（字符串或 Rule 列表） |
| **输出** | `nil`（校验通过）或 `errx.Error`（校验失败） |
| **约束** | 基于 `validx` 封装，提供 `Validate(value, rules)`、`ValidateField(value, rules)` 等快捷函数；错误通过 `errx` 封装；与 validx 原生 API 行为一致，仅做错误封装层 |
| **验收标准** | ① 校验通过返回 nil；② 校验失败返回 errx 封装错误；③ 规则语法与 validx 完全兼容；④ 单测覆盖各类规则通过/失败场景 |

### C11 统一错误封装

| 维度 | 内容 |
|------|------|
| **场景** | 所有转换/校验失败的错误需统一格式，便于上层错误处理、日志、监控 |
| **输入** | 内部错误（原生 error 或转换失败信息）、上下文（源类型、目标类型、字段路径、值摘要） |
| **输出** | `errx.Error`，携带错误码、Kind、上下文字段 |
| **约束** | 所有导出函数返回的 error 均为 `*errx.Error` 类型（或实现 errx 接口）；定义专用错误码：`ErrConversionFailed`、`ErrValidationFailed`、`ErrOverflow`、`ErrUnknownFormat`、`ErrCircularReference`、`ErrDuplicateConverter`；错误必须携带 `source_type`、`target_type` 字段；结构体/map 转换错误携带 `field_path`（如 `User.Address.City`）；禁止 panic、禁止吞 error（不提供无 error 返回值的 API 变体） |
| **验收标准** | ① 所有导出函数错误均为 errx 类型；② 错误码与场景对应正确；③ 上下文字段完整可追溯；④ field_path 嵌套路径正确；⑤ 单测断言错误码、Kind、关键字段 |

## 3. 次要需求（P1）

### S01 零反射高性能路径（V2）

| 维度 | 内容 |
|------|------|
| **场景** | 高频转换场景（如每秒十万次 DTO 转换），反射成为性能瓶颈 |
| **输入** | 同 C01-C04 |
| **输出** | 同 C01-C04，但性能更优 |
| **约束** | V2 引入，V1 API 完全兼容；针对基础类型转换使用类型断言直转（零反射）；针对结构体转换提供代码生成或类型缓存的快速路径；性能不达标时自动回退到反射路径；Benchmark 对比 V1 反射路径 |
| **验收标准** | ① 基础类型转换性能优于 `spf13/cast` 20%+；② 结构体转换性能优于 `mapstructure` 30%+；③ V1 API 行为不变；④ 单测 + Benchmark 全覆盖 |

### S02 结构体元信息并发缓存（V2）

| 维度 | 内容 |
|------|------|
| **场景** | 结构体转换首次需反射解析字段映射，重复转换同一类型时应复用元信息 |
| **输入** | 结构体类型 |
| **输出** | 缓存的字段映射元信息 |
| **约束** | V2 引入；使用 `sync.Map` 或读写锁保护的 map 缓存；并发安全；内存有界（可配置最大缓存类型数，LRU 淘汰）；缓存命中后零反射获取元信息 |
| **验收标准** | ① 同类型第二次转换命中缓存；② 并发读写无数据竞争（-race 通过）；③ 缓存淘汰策略正确；④ Benchmark 展示缓存命中性能提升 |

## 4. 兼容需求（P0）

### K01 Go 版本兼容

| 维度 | 内容 |
|------|------|
| **约束** | `go.mod` 指定 `go 1.26.5`；使用泛型、`any`、`errors.Is/As` 等 1.26 稳定特性；不使用实验性 API；CI 覆盖 1.26.5 及以上版本 |
| **验收标准** | `go build` 在 1.26.5+ 通过；`go vet` 无警告 |

### K02 跨平台兼容

| 维度 | 内容 |
|------|------|
| **约束** | 支持 Linux / macOS / Windows；支持 amd64 / arm64；不使用平台特定 API（如 `syscall` 直接调用）；时间处理使用标准库 `time`，不依赖系统时区数据库以外的资源 |
| **验收标准** | CI 在三大平台 × 两大架构下 `go test` 全部通过 |

### K03 家族库兼容

| 维度 | 内容 |
|------|------|
| **约束** | 运行时依赖 `errx`（≥v1.5.7）、`validx`（≥v1.2.5）；测试依赖 `testx`（≥v1.4.5）；错误类型与 `errx.Error` 完全兼容（支持 `errors.As` 提取）；校验规则与 `validx` 语法完全一致；不引入家族库以外的第三方依赖 |
| **验收标准** | ① `errors.As(err, &errxErr)` 可提取；② validx 规则字符串直接可用；③ `go mod graph` 无第三方非家族依赖 |

## 5. 废弃需求（明确不做）

| 编号 | 需求 | 不做原因 |
|------|------|---------|
| D01 | ORM / 数据库映射 | 超出类型转换范畴，应使用 GORM/sqlx 等专用库 |
| D02 | 完整序列化框架（JSON/XML/YAML 编解码） | 应使用标准库 `encoding/json` 等；本库仅处理已解析为 Go 值后的转换 |
| D03 | 深拷贝独立 API | 结构体转换为字段值复制语义，不提供递归深拷贝 |
| D04 | 表达式引擎（JMESPath/jq 路径查询） | 仅做直接类型转换，不做数据查询 |
| D05 | 独立代码生成 CLI 工具 | V2 高性能路径若用代码生成，作为库内部机制，不交付独立 CLI（V2 阶段再评估） |
| D06 | 跨语言绑定（CGO/FFI） | 仅面向 Go 语言 |
| D07 | 无 error 返回值的 API 变体 | 全局约束禁止吞 error，不提供 `ToXxx()` 仅返值不返 error 的函数 |
| D08 | panic 版本 API（`MustXxx`） | 全局约束禁止 panic，不提供 `MustToXxx()` 系列 |
